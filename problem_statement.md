# Problem Statement

## 1. Title
Online Fashion Shopping System

## 2. Domain
E-Commerce

## 3. Who is the User? (2–3 user types, with roles)

User:
- Register an account
- Login to the application
- Browse products
- Add products to cart
- Place orders

Admin:
- Add new products
- Update product details
- Delete products
- View customer orders

## 4. What problem are we solving? (3–5 sentences, real-life example)

Many people prefer shopping online because it saves time and offers convenience. Visiting physical stores can be difficult due to distance, traffic, or lack of time. This application helps users browse fashion products, add them to a shopping cart, and place orders from anywhere. It provides a simple and user-friendly online shopping experience.

## 5. Proposed Solution (what the application will do, feature-wise)

The application will provide the following features:
- User Registration
- User Login
- Browse Products
- Search Products
- Add to Cart
- Checkout
- Order Confirmation
- Admin Product Management

## 6. Core Entities / Database Tables (minimum 5)

1. Users
2. Products
3. Cart
4. Orders
5. Order_Items

## 7. User Roles & Permissions (minimum 2 distinct roles)

Admin:
- Manage products
- Add products
- Update products
- Delete products
- View customer orders

User:
- Register
- Login
- Browse products
- Add products to cart
- Place orders

## 8. Success Criteria

- A user should be able to register successfully.
- A user should be able to log in successfully.
- A user should be able to browse products.
- A user should be able to add products to the cart.
- A user should be able to complete an order in less than one minute.

## 9. Out of Scope

The following features are not included in the MVP:
- Online Payment Gateway
- Wishlist
- Product Reviews and Ratings
- Live Chat Support
- Admin Analytics Dashboard

## 10. Chosen Track

Java (Spring Boot)
